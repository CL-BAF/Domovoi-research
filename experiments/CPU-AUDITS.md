# CPU audits and integration records

This index preserves successive tests instead of treating the latest suite as proof for every earlier claim. The original public baseline reference is [5e76fc7](https://github.com/CL-BAF/Domovoi-Labs/tree/5e76fc78bbe9a5c12690e84d7c29e558248e6feb). Development revisions [f5fac7a](https://github.com/CL-BAF/Domovoi-Labs/commit/f5fac7a34a211adf93e0dc8ea576c8d973ef87ac) and [d914684](https://github.com/CL-BAF/Domovoi-Labs/commit/d914684dc730cd32132aeff389d6291c447ed7e4) preserve the later audit sources and regression tests. Earlier working trees without Git have no exact per-round commit.

| Audit or integration stage | Verified record | Evidence scope |
|---|---|---|
| Original independent baseline | 75 original tests passed against pinned public reference. | Compatibility. DML-0001 raw historical artifacts preserved separately. |
| Initial recurrent audit | 138 passed including 63 recurrent cases. 96 FP64 chunk cases checked causal/cache agreement and independent shared gradients. | Zero observed future-token leakage, 2.22e−16 cached-logit and 6.94e−18 gradient max deltas on tested examples. Same-shape cache and checkpoint defects discovered. |
| Post-audit fixes and re-review | Historical runs reported 207, 222 and 234 CPU passes across correction rounds. | Shape/signature validation, malformed caches, accounting, writer locks, backup load and data provenance. [Preserved repro and mutation outputs](data/archive/cpu-audit/) |
| Independent re-review at 234 tests | Forced interruption during optimizer update exposed torn checkpoint, injected NaN confirmed invalid COMPLETED, and replay exposed duplicated metrics. | Controlled injections, followed by regression coverage. Later fixed in Round 4. |
| Round 4 and pilot plumbing | Round 4 reported 256 CPU passes. Pilot implementation reached 267 CPU passes and one CUDA-only skip. Separate RTX profiling smoke passed. | Strict trajectory fields, clean recoveries, no-repeat sampling, exact full-split accumulation and resource gates. |
| Real-data source and publication | Initial streaming suite reported 272 passes plus one GPU-only skip. Final d914684 rerun reported **275 passes and one CUDA-only skip** on CPU with the known scheduler monkeypatch warning. | Repeated for archive verification without starting training on the RTX 5080 beyond scoring saved checkpoints. |

The research question was whether causal and recurrent mechanics, state consistency and audit guards survived controlled adversarial inputs. The hypothesis of equivalence for depth one and valid-cache decode is supported within tested shapes. Invalid cache and resume probes contradicted assumed guard coverage before fixes. Tests include synthetic step training and temporary artifacts. They do not establish capability, a general performance envelope, or cross-device numerical determinism.

Source-linked detailed [independent audit](https://github.com/CL-BAF/Domovoi-Labs/blob/d914684dc730cd32132aeff389d6291c447ed7e4/CODEX_INDEPENDENT_AUDIT.txt), [verification log](https://github.com/CL-BAF/Domovoi-Labs/blob/d914684dc730cd32132aeff389d6291c447ed7e4/CODEX_VERIFICATION_RESULTS.txt), and [fix history](https://github.com/CL-BAF/Domovoi-Labs/blob/d914684dc730cd32132aeff389d6291c447ed7e4/POST_AUDIT_FIXES.txt) retain commands, limitations and reproduction details. Existing local repro logs have been copied into the archive after replacing machine-local paths with placeholders. Complete byte-for-byte logs for all historical test invocations do not exist.
