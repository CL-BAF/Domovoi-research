# DML-0001 · Partial baseline pipeline run

**Historical run:** September 2026. **Record assembled:** 23 November 2026. **Recorded status:** `RUNNING` in the preserved metadata. Artifacts end at step 520 of 3,000. The terminal event is not independently established from the four available files.

## Question and expected behavior

DML-0001 exercised the baseline training pipeline on a small, repeatable input. Before the run, the useful expectation was that the optimizer would reduce next-token loss and the pipeline would emit attributable configuration and metrics. Tinyshakespeare is narrow and repeatedly sampled at this token budget, so these results cannot test general capability or compare parameter sharing.
